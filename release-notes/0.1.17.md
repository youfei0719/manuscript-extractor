# 稿件提取 v0.1.17

## 更新内容

- 修复旧版本选择 TokenFlux 后仍调用 OpenAI 远程转写的问题：营销号文稿分析密钥只用于文本校对，默认转写自动使用本机 MLX Whisper。
- 修复识别工作台步骤连接线穿过文字、窄窗口标题区挤压和内容溢出问题，步骤信息在不同窗口宽度下保持完整可读。
- 修复应用内检查更新的发布链路：资产使用稳定的软件名与版本号，更新元数据使用可直接下载的 GitHub Release 地址。
- 保留 v0.1.16 及更早版本的 GitHub Release，用户可在应用内查看更新说明后选择更新。

## 安全与数据

- API Key、Cookie、更新签名私钥和本机媒体不会提交到代码、发布资产或运行日志。
- 旧配置只做本地兼容迁移，不会读取、打印或上传已有密钥。

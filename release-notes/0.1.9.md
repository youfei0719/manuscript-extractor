# 稿件提取 v0.1.9

## 更新内容

- 统一修正 GitHub Release 资产命名：macOS DMG、macOS updater 包、Windows EXE 和 MSI 均显示“稿件提取_版本号_系统架构”。
- 发布流程会在构建完成后自动整理资产，并生成带签名地址的 `latest.json`。
- 应用内检查更新会读取最新版本、中文更新说明和对应平台的签名包，用户确认后直接下载、安装并重启。
- 历史版本继续保留，方便回滚和归档。

## 安全与数据

- updater 签名私钥只保存在 GitHub Actions Secret。
- API Key、Cookie 等敏感信息只保存在系统凭据库，原始媒体只在本机临时处理。

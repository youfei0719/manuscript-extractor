# 稿件提取 v0.1.18

## 更新内容

- 重做原始转写编辑区：使用完整宽度的文稿编辑器，增加字数与编辑状态提示，改善中文字号、行距、内边距和移动端布局，避免稿件缩在狭窄小框中。
- 优化自然分段：保留用户已有空行，按句末标点、逗号与分号等弱边界、常见语义转折词处理连续 ASR 文本；即使原始转写缺少标点，也不会再显示成一整块难以阅读的文字。
- 统一 AI 校对交互：运行按钮增加点击反馈、运行中的图标旋转与轻量流光，校对结果和修改建议使用渐进出现动画；支持系统“减少动态效果”设置。
- 修复运行日志错误分类：HTTP 401/403、429、500/502/503/504、网络连接失败、模型响应格式错误分别记录为可行动的错误码，不再把上游 502 误记为“响应无效”。
- 502 根因说明：本次错误发生在文本模型服务商的上游网关阶段，媒体下载、音频提取和本机 MLX 转写均已成功；应用会继续给出服务商不可用的准确提示，并保留重试与切换模型建议。

## 安全与数据

- API Key、Cookie、更新签名私钥、本机媒体和运行日志中的敏感信息不会提交到代码或发布资产。
- 发布资产继续保留历史版本，并使用带软件名、版本号和平台的稳定文件名。

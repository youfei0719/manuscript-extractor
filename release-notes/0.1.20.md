# 稿件提取 v0.1.20

## 更新内容

- 修复 TokenFlux 模型错误诊断：统一解析 `error.message`、顶层 `message`、服务商错误码和脱敏请求标识。
- 修正错误报表分类：上游认证失败和上游拒绝访问归类为 `LLM_AUTH_FAILED`；账号耗尽、分组无可用账号和服务过载保留为 `LLM_PROVIDER_UNAVAILABLE`。
- 模型列表、连接测试和 AI 校对现在使用同一套错误处理逻辑，避免同一个问题显示不同结论。
- 当服务商只返回通用 HTTP 502 时，显示服务商错误码和明确的排查方向，不再假装知道未知根因。
- 重做 AI 校对交互状态：连接模型、校对稿件、整理语义段落和失败重试均有对应状态反馈。
- 校对失败后保留原始转写，可直接重新运行，不会丢失当前稿件。

## 安全与数据

- API Key、Cookie、更新签名私钥、完整上游响应和本机路径不会提交到代码、发布资产或运行日志。
- 请求标识仅用于排查，经过脱敏和长度限制。

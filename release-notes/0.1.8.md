# 稿件提取 v0.1.8

## 更新内容

- 修正所有 updater 与安装资产的文件名，统一为“稿件提取_版本号_系统架构”。
- 新增自动生成并上传 `latest.json`，应用内“检查更新”现在可以直接识别 macOS 与 Windows 新版本。
- 保留每个历史版本 Release，不覆盖既有安装包。
- 延续设置与诊断页面重构、版本号显示、中文更新说明弹窗、识别进度条和阶段动效。

## 安全与数据

- 更新包使用 Tauri updater 签名校验；签名私钥只保存在 GitHub Actions Secret。
- API Key、Cookie 等敏感信息只保存在系统凭据库，原始媒体只在本机临时处理。

# 稿件提取 v0.1.6

## 更新内容

- 新增应用内检查更新：在“设置与诊断”中点击“检查更新”，发现新版本后会先展示完整更新说明，由用户选择是否下载、安装并重启。
- 更新包改为使用 Tauri 官方更新签名，GitHub Release 自动生成 `latest.json`，历史版本继续保留，不会覆盖旧版本。
- 统一安装文件命名为“软件名_版本号_系统架构”，方便识别和归档。
- 设置与诊断页面重新整理为版本信息、运行时设置、依赖检查和运行日志四个层次，减少信息割裂。
- 识别稿件新增来源、媒体、转写、校对四阶段进度条，并加入轻量状态过渡动画，让长任务当前阶段更清楚。
- 优化窄窗口下的按钮、更新弹窗和设置摘要布局。

## 安全与数据

- API Key、Cookie 等敏感信息仍只保存在系统凭据库，不写入 GitHub、数据库或运行日志。
- 原始媒体仍只在本机临时处理，确认稿才会进入本机历史。

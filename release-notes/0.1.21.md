# 稿件提取 v0.1.21

## 更新内容

- 修复 TokenFlux 仅返回通用 HTTP 502 或 `Bad Gateway` 时的提示，明确说明服务商未提供具体原因，并给出模型分组、余额和上游账号状态的排查方向。
- 修复模型列表接口成功但返回非法 JSON 时被误判为空模型列表的问题，现在统一记录为 `LLM_RESPONSE_INVALID`，不会再让设置页显示虚假的可用状态。
- 统一模型列表、连接测试和 AI 校对的响应解析与错误分类，保留服务商错误码和脱敏请求标识用于排查。
- 校对动画状态改为可验证的连接模型、校对稿件、整理语义段落三阶段；失败后稳定停在重试状态，原始转写保留不丢失。
- 增加 AI 校对状态呈现和异常响应的自动化回归测试，避免旧计时器覆盖重试状态。

## 安全与数据

- API Key、Cookie、更新签名私钥、完整上游响应和本机路径不会提交到代码、发布资产或运行日志。
- 本版本保留历史 Release，不覆盖或删除 `v0.1.20`。
